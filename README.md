# 🌐 DNS Lookup IPv6 Pro — проверяй AAAA-записи и обратные зоны за секунды

> «IPv6 — это будущее, проверь его сегодня»

**DNS Lookup IPv6 Pro** — это набор консольных утилит для массового DNS-резолвинга с фокусом на IPv6-записи (AAAA) и обратные lookup (PTR).  
Программа принимает список доменов или IP-адресов и выполняет детальную проверку IPv6-инфраструктуры.

## 🚀 Особенности
- 🔍 Проверка AAAA-записей для доменов.
- 🔄 Reverse DNS (PTR) для IPv6-адресов.
- 📋 Массовая проверка из файла (по одному домену/адресу на строку).
- ⚡ Асинхронная/конкурентная проверка для максимальной скорости.
- 📊 Вывод в удобной таблице с цветовой индикацией.
- 💾 Сохранение результатов в JSON и CSV.
- 🌍 Поддержка пользовательских DNS-серверов.
- 🎨 Цветной вывод и прогресс-бар.

## 🛠️ Установка и запуск

Для каждого языка — минимальные зависимости.

| Язык       | Зависимости                          | Команда запуска                         |
|------------|--------------------------------------|-----------------------------------------|
| Python     | `dnspython`                          | `python dns_lookup.py domains.txt`      |
| Go         | стандартная библиотека               | `go run dns_lookup.go domains.txt`      |
| JavaScript | Node.js, `dns` (встроенный)          | `node dns_lookup.js domains.txt`        |
| Java       | `dnsjava`                            | `javac -cp .:dnsjava.jar ... && java ...` |
| C#         | стандартная библиотека               | `dotnet run domains.txt`                |
| Rust       | `trust-dns-proto`, `trust-dns-resolver` | `cargo run -- domains.txt`          |
| Ruby       | `resolv` (стандартная)               | `ruby dns_lookup.rb domains.txt`        |
| PHP        | стандартная библиотека               | `php dns_lookup.php domains.txt`        |
